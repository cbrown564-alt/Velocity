# Design Iteration 04 — Slide 6 Evidence Binding

The previous Slide 6 mockup had placeholder preference/usage values. This iteration removes that blocker by recomputing the four comparable funnel stages directly from the committed deterministic SBT-001 generator (`SEED=564001`) for Waves 2 and 5.

## Bound weighted values

| Stage | W2 | W5 | Change |
|---|---:|---:|---:|
| Prompted awareness | 57.79% | 73.82% | +16.03pp |
| Total-sample consideration incidence | 20.29% | 29.59% | +9.30pp |
| Preferred brand = Pulse | 15.34% | 25.11% | +9.77pp |
| Current provider = Pulse | 15.16% | 19.79% | +4.63pp |

These values are generated from the same canonical respondent world and `wt_final` weighting logic used by SBT-001. No manual deck values are used.

## Revised visual argument

**Headline:** `Pulse is becoming mentally available faster than it is becoming customers' provider.`

**Dek:** `W2 → W5: awareness, consideration and preference all move ahead of actual usage.`

Use four aligned W2/W5 dumbbells:

1. Awareness
2. Consideration
3. Preference
4. Usage

The commentary should synthesise the uneven conversion:

> Consideration is up 9.3pp; usage is up 4.6pp. Pulse has won more mental availability than customers so far. The next test is conversion, not another awareness headline.

## Important scope decision

The earlier prototype included `Innovation` as if it were another directly comparable funnel stage. Remove it from the main four-stage visual. Brand-image innovation uses the familiar-brand routed universe, while the four stages above can be expressed as total-sample/single-brand shares. Innovation remains useful supporting evidence on the preceding campaign/audience pages, but putting it into the conversion ladder would visually imply a common denominator that does not exist.

## QA consequence

Slide 6 is no longer blocked by placeholder values. It can now enter whole-deck integration, subject to ordinary render/layout QA.
