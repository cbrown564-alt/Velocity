Visual analysis — what we gained and what we lost

Judged against the Linear bar (restrained chrome, one typographic system, content-sized layouts) and Sarah's five-minute journey.

What we gained

  • One opinionated identity. Three themes, materials, and hover animations deleted. Design surface ×3 → ×1; accent budget enforceable.
  • Story-first IA. The deck outline is resident; variables and recipe config are summoned. The product posture matches the deck-native charter.
  • Calm over the artifact. Coaching layer gone — no tours, stacked toasts, suggestion pills, or popovers on hero output. Zero interruptions in the timed pass.
  • Honest slide contract. What you see exports; stats live in a margin note outside the card. WYSIWYG trust for client deliverables.
  • Quiet toolbar. View toggle · Insert ⌘K · overflow · Export. Export is the only accent on most screens.
  • Keyboard-native insertion. Palette grammar (↵ / ⌥↵ / ⇧↵) makes the 5-minute metric achievable without a mouse after file drop.
  • Density where it matters. VM two-pane layout and palette rows scan 20–30 variables vs ~14 in the old sidebar buttons.
  • Session continuity. Story rail + recipe persistence — reopen shows the deck, not a blank canvas with amnesiac coaching.
  • Credibility signal. Restraint and craft in the tool mirror the deliverable Sarah is selling to clients.

What we lost (or traded away)

  • At-a-glance variable inventory. No resident list means experts can't scan the full field while thinking — they must summon ⌘K or open VM.
  • Drag-from-sidebar muscle memory. Primary insertion path shifted to palette keyboard grammar; drag remains but is secondary.
  • Visible starting points. Suggestion pills ("try sex × marital") removed with the coaching layer — discovery is self-directed.
  • Theme personalization. Mission Control and Liquid Glass deleted, not deprecated — some evaluators liked the choice.
  • Spatial VM navigation. Miller columns gave a mental map of folders/sets; now filter chips — faster search, less geography.
  • Rich list metadata at a glance. Sparklines and top-category chips retreated to inspector — less noise, more clicks for power users.
  • Focus mode as transformation. Default chrome is already quiet; focus hides less than before relative to the old crowded toolbar.
  • General-purpose ⌘K. Session import, reset, and settings no longer in the primary summon surface.
  • PILOT-6 photography alignment. Marketing screenshots still show pre-reset chrome — re-capture required before paid recruiting.

Key questions for convergence

These surfaced from the side-by-side review and the reset's own risk register. Each needs a product decision, not just polish.

Q1

Is summon-only variable discovery fast enough for drag-first consultants?

The palette opens in <100ms on 500 variables, but first-time users may not discover ⌘K. Watch pilot session recordings: do they hunt for a sidebar that no longer exists?

Q2

Does the story rail earn its 240px when decks have only 1–2 slides?

Sarah's Friday job is often three slides, not thirty. An empty or single-slide rail may feel like dead space — the inverse of the old variable sidebar problem.

Q3

Where does "review before export" live in the journey?

Recipe inspector makes slide state visible, but export is still fire-and-download. Is a deck preview lane needed before PPTX — especially for agent-built sessions?

Q4

Can we teach palette grammar without reintroducing coaching?

The footer hints (↵ / ⌥↵ / ⇧↵) help power users. First-run empty state says "press ⌘K" — is that sufficient, or do we need a one-time inline demo that never returns?

Q5

Is focus mode still a mode — or should default chrome be the presentation surface?

Pathway D (workbench vs present split) was rejected. With honest slides and quiet chrome, does focus become redundant or should it hide the story rail too?

Q6

How do we onboard agents and humans to the same deck grammar?

MCP agents build slides programmatically; humans use palette + rail. Misalignment shows up in handoff evals — does the UI make recipe structure legible enough for additive refinement?

Q7

When do we invest in dark mode vs journey polish?

Deferred until a pilot asks — but late-night strategists exist. Does dark mode wait, or does export preview / workspace reopen (STAB-WS) take priority?

Diverse paths forward

Not a roadmap — options to discuss and converge. All paths keep the central journey lens: file-drop → three slides → PPTX, delightful and easy.

Validate · Low risk

A. Pilot-first evidence loop

Re-run PILOT-6 photography on post-reset UI. Record 3–5 unscripted first sessions. Score: time-to-first-crosstab, palette discovery rate, interruption count. Let behavior decide whether summon-only insertion holds.

Trade-off: delays feature work; highest confidence in convergence.
Journey · Medium

B. Export preview lane

Add a review step between canvas and download: thumbnail filmstrip of export-bound slides, recipe summary, significance audit. Makes "trust the numbers" tangible without coaching popovers.

Trade-off: adds a click; may save client embarrassment. Serves agent handoff (EVAL-03).
Discovery · Medium

C. Thin "recent & pinned" strip

Not a full variable wall — a 32px collapsible row of last-used and pinned variables below the toolbar. Preserves scan speed for experts without resurrecting the 44px button list.

Trade-off: reintroduces resident chrome; must stay under accent budget and density rules.
Keyboard · Medium

D. Palette onboarding moment (once)

First ⌘K on a new workspace: inline 3-step ghost (search → ↵ columns → ⌥↵ rows) inside the palette itself — dismiss forever, no tour overlay. Teaches grammar without coaching layer architecture.

Trade-off: one exception to "zero coaching"; must not persist or reappear on reopen.
Story · Higher

E. Deck templates for tracker debriefs

Workspace entry: "Start from template" → 3-slide brand tracker skeleton (awareness · consideration · preference). Story rail pre-populated; Sarah replaces variables via palette.

Trade-off: scope creep toward content product; high journey delight if templates match ICP workflows.
Natural language · Higher

F. "Q5 by segment" in the palette

Extend insert palette with natural-language row/column parsing (not full AI analysis — just variable binding). Speaks Sarah's language; keeps inspectability.

Trade-off: engineering + eval cost; must not become magic-button Displayr positioning.
Polish · Low

G. Collapsible story rail

Rail collapses to icon strip (<48px) on single-slide sessions; expands on hover or when deck grows. Reclaims horizontal space without losing deck-native IA.

Trade-off: motion + state complexity; test against "one transition" rule (WP3.2).
Continuity · Medium

H. Workspace → canvas handoff polish

After upload, land directly on slide 1 with palette pre-focused (not empty canvas waiting for a click). Reduce the "now what?" beat between Workshop Door and first insertion.

Trade-off: may feel pushy if user wanted to browse workspace first; gate on dataset size.
Agent · Medium

I. Recipe diff for MCP handoff

When importing an agent session, show a quiet "what changed" summary in the story rail footer — slides added, variables unresolved. Supports additive refinement without modal interruption.

Trade-off: agent-specific UI; must stay muted per calm-tech rules.
Hold · Deferred

J. Dark mode of the same identity

Ship dark as token inversion of evolved Soft Machine — not Mission Control reborn. Only when a pilot blocks without it.

Trade-off: doubles visual QA surface; does not advance the five-minute journey directly.
