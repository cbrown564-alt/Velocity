North star — design notes

Phase 0 of the design reset (plan_04, Pathway B). Four target states, judged against: file-drop → three titled slides → PPTX in under 5 minutes, zero interruptions, at most one accent element visible.

Tokens — evolved Soft Machine

Ground — app surface#F1EFEA
Panel — the slide only#FDFCFA
Ink — green-ink text#24302A
Ink 2 — secondary#67736C
Accent — sienna#B54E33
Mark — data bars#6F8177

Type

Production: Fraunces (slide titles only), Plus Jakarta Sans (all chrome), JetBrains Mono (data, tabular). This mock uses system stand-ins (Palatino / system sans / SF Mono) because it is dependency-free.

Rules this mock encodes

  • Accent budget: sienna appears only on Export and significance arrows. Screen 2 has zero accent (Export disabled); screen 4 has zero accent.
  • The slide is the only white object. Everything else recedes into warm gray. What you see is what exports; stats live in the margin note, outside the artifact.
  • The story is the navigation. Left rail is the deck outline. No variable wall, no timeline dock.
  • Variables are summoned, not resident. ⌘K opens the insert palette (try it on screens 1–2). Enter adds to rows; modifiers to columns/filter.
  • The recipe is slide state. Rows/columns/filter/weight sit in a collapsed right inspector (toggle “Recipe”), not persistent shelf chrome.
  • Two-pane Variable Manager. Search + filter chips + dense 32px rows + inspector. Type is a monochrome glyph; color is reserved for meaning.
  • Empty state = one line + one action. No tours, tips, pills, or toasts anywhere.

Try

  • Keys 1–4 switch screens
  • ⌘K / Ctrl-K opens the palette; esc returns
  • Recipe toggles the slide inspector on screen 1
